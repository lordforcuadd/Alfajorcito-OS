# ARCHITECTURE & DESIGN DECISION LOG: Alfajorcito OS

| ID | Fecha | Contexto / Problema | Alternativas Evaluadas | Decisión Adoptada | Motivo / Justificación | Consecuencias |
| :--- | :---: | :--- | :--- | :--- | :--- | :--- |
| **ADR-001** | 2026-08-15 | Elección de la plataforma y runtime base | PWA Local-First vs React Native Nativo vs Fullstack Cloud | **PWA Local-First (React 19 + Vite + Dexie.js)** | Permite disponibilidad offline inmediata sin costes de servidor ni fricción de tiendas de apps, funcionando con excelente rendimiento en móviles y tablets. | Máxima privacidad y velocidad; requiere exportación manual o sync P2P para backups entre dispositivos. |
| **ADR-002** | 2026-08-15 | Motor de almacenamiento de datos en cliente | IndexedDB nativo vs LocalStorage vs Dexie.js vs SQLite WASM | **Dexie.js (IndexedDB)** | Soporta esquemas relacionales, índices multi-campo y reactividad nativa en React (`useLiveQuery`) sin el peso ni complejidad de WASM. | Consultas reactivas instantáneas (<5ms) y capacidad de almacenamiento de decenas de gigabytes. |
| **ADR-003** | 2026-08-15 | Sistema de Diseño y Estética Visual | UI de dashboard oscura vs Estilo Notion genérico vs Pastel Académico Premium | **Pastel Académico Premium** | Proporciona calidez visual relajante con tonos rosa empolvado, lavanda y crema sin sacrificar contraste WCAG AA ni parecer infantil. | Identidad visual única y distinguida orientada a largas sesiones de estudio. |
| **ADR-004** | 2026-08-15 | Integraciones Académicas para Metadatos | Web scraping frágil vs APIs oficiales abiertas (OpenAlex, Crossref, Semantic Scholar) | **APIs directas abiertas + Negociación CSL-JSON** | Protocolos estables con soporte CORS directo desde el navegador que devuelven metadatos estandarizados de millones de publicaciones. | Consultas oficiales sin riesgo de bloqueo por captcha o cambios de HTML. |
| **ADR-005** | 2026-08-15 | Regla de Oro Anti-Alucinación | Autocompletado generativo de campos vs Marcado explícito de datos ausentes | **Marcado imperativo `DATO NO VERIFICADO`** | En el ámbito académico inventar un autor o DOI acarrea acusaciones de fraude o plagio involuntario. | La IA jamás inventa metadatos; el usuario mantiene el control de la veracidad. |
| **ADR-006** | 2026-08-15 | Compatibilidad de Segundo Cerebro | Formato propietario JSON vs Markdown compatible con Obsidian | **Markdown con YAML Frontmatter + [[wikilinks]]** | Garantiza la propiedad y longevidad de las notas del usuario fuera de la aplicación. | Exportación directa a vaults de Obsidian en un solo archivo ZIP organizado. |
