# 🌸 Alfajorcito OS

> **Centro de Operaciones Académicas + Investigación + Segundo Cerebro Móvil/Tablet**
> *Local-First • Offline-Ready • Compatible con Obsidian • Rigor Anti-Alucinación*

---

## 🌟 Resumen del Producto
**Alfajorcito OS** es un entorno integral de trabajo académico diseñado para acompañar el ciclo de vida completo de un estudiante o investigador universitario:

$$\text{Instrucciones} \longrightarrow \text{Análisis} \longrightarrow \text{Dudas con Profesor} \longrightarrow \text{Investigación} \longrightarrow \text{Evaluación} \longrightarrow \text{Ideas} \longrightarrow \text{Paráfrasis} \longrightarrow \text{Citas} \longrightarrow \text{Referencias} \longrightarrow \text{Redacción} \longrightarrow \text{Feedback} \longrightarrow \text{Conocimiento Permanente}$$

---

## ✨ Características Principales

1. **Dashboard Operativo**: Responde al instante las 8 preguntas críticas del día a día académico.
2. **Workspace por Trabajo Académico**: Desglose riguroso de rúbricas (separando consignas oficiales de inferencias de IA), checklist y control de antigüedad máxima de fuentes.
3. **Módulo de Consultas al Docente**: Registro de dudas, redacción de preguntas formales y documentación de respuestas vinculantes que prevalecen sobre la IA.
4. **Búsqueda e Investigación Académica**: Conexión directa a OpenAlex, Crossref, Semantic Scholar y resolución de DOI con metadatos oficiales y regla estricta anti-alucinación (`VERIFIED`, `PARTIALLY_VERIFIED`, `UNVERIFIED`).
5. **Trazabilidad Epistemológica**: Cadena inquebrantable de atribución desde la fuente original, la idea, la paráfrasis propia con advertencia de fidelidad, hasta la cita y referencia bibliográfica.
6. **Motor de Citación Multiformato**: Generación determinista para APA 7ma Ed., MLA 9na Ed., IEEE, Chicago (Autor-Fecha y Notas) y Vancouver.
7. **Segundo Cerebro & Notas Atómicas**: Editor Markdown con `[[wikilinks]]`, tags, visualizador interactivo de grafo de conocimiento y exportación directa a Vault de Obsidian (.zip).
8. **Integraciones Reales**: Exportación con sangría francesa para Google Docs, sincronización de fechas con Google Calendar (.ics/Intents) y enlace a plantillas de Canva.
9. **Diseño Visual Pastel Premium**: Paleta relajante accesible (rosa empolvado, lavanda, crema y pizarra profunda), mobile-first con Split View para tablets.
10. **100% Local-First & Offline**: Datos almacenados en IndexedDB con soporte PWA completo sin dependencia de servidores externos.

## 🚀 Inicio Rápido

### Requisitos
- Node.js 18+ o superior.
- Navegador moderno (Chrome, Safari, Firefox, Edge).

### Instalación y Ejecución Local
```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev

# 3. Compilar para producción
npm run build

# 4. Ejecutar suite de pruebas
npm run test
```
